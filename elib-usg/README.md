# Portal Layanan — Perpustakaan Universitas Sunan Gresik

Portal layanan digital perpustakaan USG dengan tampilan ultra-modern bento grid.

**Live Preview:** _(akan tersedia setelah deploy ke Cloudflare Pages)_

---

## Tech Stack

- **HTML5** — semantic & accessible
- **CSS3** — bento grid, responsive, custom properties
- **Vanilla JavaScript** — live clock, animated counter, search handler
- **Lucide Icons** — via CDN
- **Google Fonts** — Inter + JetBrains Mono

Tidak butuh build tools, tidak butuh framework. Buka langsung di browser bisa jalan.
